# Responsive Business Website

A modern, multi-page corporate business website built with *React.js* and *React Router*.

## 🚀 Features
* *Multi-Page Navigation:* Seamless page switching between Home, Services, and Portfolio using React Router without full reloads.
* *Modern UI & Layout:* Clean CSS grid layouts with reusable card components to showcase services and past projects.
* *Light / Dark Mode:* Integrated dynamic theme switcher for user preference and accessibility.
* *Fully Responsive:* Optimized for both mobile devices and desktop screens.

## 🛠️ Tech Stack
* *Frontend:* React.js, React Router DOM
* *Styling:* Custom CSS (Flexbox, Grid, Themes)
* *Build Tool:* Vite
